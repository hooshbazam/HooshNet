# 🚀 هوش‌نت (HooshNet)
**سیستم جامع و حرفه‌ای مدیریت فروش و ارائه سرویس‌های VPN**

هوش‌نت یک پلتفرم قدرتمند، امن و مقیاس‌پذیر برای راه‌اندازی کسب‌وکارهای فروش VPN است. این پروژه با بهره‌گیری از معماری **Docker** و زبان‌های **Python** و **JavaScript**، یک راهکار کامل شامل **ربات تلگرام پیشرفته** و **وب‌اپلیکیشن مدرن** را در اختیار شما قرار می‌دهد.

---

## ✨ چرا هوش‌نت؟

### 🤖 ربات تلگرام هوشمند
*   **فروش خودکار:** اتصال به درگاه‌های پرداخت (زرین‌پال، نکست‌پی و ...) و تحویل آنی سرویس.
*   **مدیریت چندگانه:** پشتیبانی همزمان از پنل‌های **3x-ui**، **Marzban**، **Hiddify** و ...
*   **پنل ادمین کامل:** مدیریت کاربران، سرویس‌ها، تخفیف‌ها و گزارشات مالی بدون خروج از تلگرام.
*   **سیستم تیکتینگ:** پشتیبانی حرفه‌ای از کاربران با قابلیت ارجاع به دپارتمان‌های مختلف.
*   **گردونه شانس:** ابزار مارکتینگ جذاب برای افزایش تعامل کاربران.

### 🌐 وب‌اپلیکیشن PWA
*   **داشبورد کاربری:** مشاهده وضعیت سرویس، حجم باقی‌مانده و تاریخ انضا.
*   **تمدید آسان:** امکان تمدید سرویس‌ها با چند کلیک.
*   **گزارشات مالی:** دسترسی به تاریخچه تراکنش‌ها و فاکتورها.
*   **طراحی ریسپانسیو:** تجربه کاربری عالی در موبایل و دسکتاپ.

### ⚙️ زیرساخت حرفه‌ای
*   **معماری Docker:** نصب و راه‌اندازی ایزوله، پایدار و بدون تداخل.
*   **دیتابیس MySQL:** ذخیره‌سازی مطمئن و بهینه اطلاعات با قابلیت بکاپ‌گیری خودکار.
*   **مدیریت آسان:** اسکریپت مدیریت اختصاصی (`manager.sh`) برای کنترل کامل سیستم.
*   **مانیتورینگ:** نظارت لحظه‌ای بر منابع سرور و وضعیت سرویس‌ها.

## 📥 نصب و راه‌اندازی (Easy Install)

تنها با اجرای یک دستور، کل سیستم به صورت خودکار نصب و پیکربندی می‌شود. اسکریپت هوشمند ما تمامی پیش‌نیازها (Docker, Docker Compose و ...) را بررسی و نصب می‌کند.

### 🚀 دستور نصب سریع

```bash
git clone https://github.com/hooshbazam/HooshNet.git && cd hooshnet && chmod +x installer.sh && sudo ./installer.sh
```

پس از اجرای دستور، منوی نصب ظاهر می‌شود. گزینه **Install** را انتخاب کنید و مراحل را دنبال نمایید.

### 🐳 نصب دستی (Manual Docker Install)

اگر ترجیح می‌دهید نصب را به صورت دستی انجام دهید:

1.  ابتدا مخزن را کلون کنید:
    ```bash
    git clone https://github.com/hooshbazam/HooshNet.git && cd hoshnetsc
    ```
2.  فایل کانفیگ را ایجاد کنید:
    ```bash
    cp .env.example .env
    nano .env  # تنظیمات خود را وارد کنید
    ```
3.  کانتینرها را بیلد و اجرا کنید:
    ```bash
    docker compose up -d --build
    ```
4.  اسکریپت مدیریت را فعال کنید:
    ```bash
    chmod +x manager.sh
    sudo ./manager.sh install  # برای ایجاد شورتکات hooshnet
    ```

## 🛠 مدیریت پروژه

پس از نصب، می‌توانید با استفاده از دستور سراسری `hooshnet` یا اسکریپت `manager.sh` به منوی مدیریت دسترسی داشته باشید.

### دسترسی به منوی مدیریت
```bash
hooshnet
# یا
./manager.sh
```

### امکانات منوی مدیریت:
1.  **Install / Reinstall:** نصب مجدد یا تعمیر پروژه.
2.  **Start Services:** راه‌اندازی سرویس‌ها (Bot, WebApp, Database).
3.  **Stop Services:** توقف تمامی سرویس‌ها.
4.  **Restart Services:** راه‌اندازی مجدد سرویس‌ها.
5.  **View Logs:** مشاهده لاگ‌های سیستم برای عیب‌یابی.
6.  **Update Project:** بروزرسانی هوشمند پروژه به آخرین نسخه.
7.  **System Status:** مشاهده وضعیت منابع سرور (CPU, RAM).
8.  **Backup / Restore:** مدیریت فایل‌های پشتیبان دیتابیس.

## 📋 پیش‌نیازها

*   **سیستم عامل:** Ubuntu 20.04+ (پیشنهادی) یا هر توزیع لینوکس با پشتیبانی از Docker.
*   **منابع:** حداقل 1 هسته CPU و 1GB رم.
*   **پورت‌ها:** پورت‌های 80/443 (برای وب‌اپ) و پورت‌های پنل VPN باید آزاد باشند.
